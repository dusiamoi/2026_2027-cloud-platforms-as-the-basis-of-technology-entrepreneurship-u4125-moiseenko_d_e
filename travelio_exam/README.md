# Travelio Booking — экзаменационная работа

Проект повторяет состав лабораторной №4: отчёт, три состояния архитектуры, экономическая модель, результаты расчёта и редактируемая схема.

## Содержимое

- lab4_report.md — описание кейса, допущений, архитектуры, пиков, надёжности и безопасности.
- cost_model.py — простая модель ориентировочных затрат.
- cost_results.json — результаты последнего пересчёта.
- diagrams/travelio-infrastructure.drawio — три страницы схемы, редактируемые в diagrams.net.
- diagrams/*.svg — схемы для просмотра прямо на GitHub.

## Пересчёт

Нужен Python 3, сторонние пакеты не требуются:

    python cost_model.py

Тарифы в модели — иллюстративные плановые допущения, а не коммерческое предложение. Перед сдачей или бюджетированием замените, прежде всего, оценку Elastic Cloud и ресурсы GCP значениями выбранного региона и конфигурации.
